# DOTFILES

This repository contains several install scripts for setting up a base environment on linux machines. This is tested on Ubuntu 24.04, and expected to work on machines Ubuntu/debian machines.

Install by just running the `install.sh` file, or running this command:
```
curl -sSL https://raw.githubusercontent.com/alphillips-lab/dotfiles/refs/heads/main/install.sh | bash
```
